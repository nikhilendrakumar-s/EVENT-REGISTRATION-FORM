EVENT REGISTRATION FORM

Files:
- index.html: Form structure
- style.css: Page design
- script.js: Form submission and display logic

How to run:
1. Extract the ZIP file.
2. Open the event_registration_form folder.
3. Double-click index.html (or open it in a web browser).
4. Enter your name and email, select an event, and click Submit Registration.
5. Your entered details will appear below the form.

This is a front-end demo. It displays the details in the browser and does not save or send registrations to a server.
